# Exercise photos

Drop a photo here named after the exercise and it appears on that exercise's
card automatically. Nothing else to edit.

The filename is the exercise name, lowercased, with apostrophes removed and
every run of non-letters replaced by a single hyphen, ending in `.jpg`:

| Exercise on the page | Filename |
| --- | --- |
| Leg Press | `leg-press.jpg` |
| Chest Press Machine | `chest-press-machine.jpg` |
| Cable Rope Hammer Curl | `cable-rope-hammer-curl.jpg` |
| Captain's Chair Leg Raise | `captains-chair-leg-raise.jpg` |

A missing file is not an error — the card just shows no photo, so add them one
at a time as you go. Photos of the actual machines in your gym beat any stock
image, since the card only has to answer "which machine is this and how do I sit
on it".

Keep them small (under ~200 KB, roughly 1000px wide) so the page stays fast.
